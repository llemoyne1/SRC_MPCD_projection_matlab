# Weighted resampling: periodic step visual stress case

This patch adds a fully periodic step/shear test for the weighted-resampling MATLAB branch.

The purpose is to test the resampling method after the initial depleted-patch smoke, but before reintroducing physical walls, immersed solids, inlet/outlet conditions, or the historical backward-step scripts.

## New files

```text
resamp_initialize_particles_periodic_step.m
resamp_periodic_step_visualize_frame.m
run_resamp_periodic_step_visual_demo.m
doc/README_RESAMPLING_PERIODIC_STEP.md
```

No existing function is modified.

## Physical role

The initializer creates an exact-per-cell periodic support and assigns a staircase velocity field:

```text
U = ULower below a piecewise-constant interface y_s(x)
U = UUpper above it
```

The interface is periodic and has no wall meaning.  It is only a strong-gradient initial condition meant to generate shear, vorticity, population transport, and possible local underpopulation during the evolution.

The weighted-resampling loop is the same as in the pool-insertion visual demo:

```text
weighted classic or weighted Q6 step
underpopulated-cell insertion
local mass/momentum remap
optional weighted thermostat after remap
```

## Main diagnostics

The CSV is written to:

```text
runs/resamp_periodic_step_visual/resamp_periodic_step_visual_<method>.csv
```

Important fields:

```text
NpActive, Ncapacity, Nfree
NMin, NMax, NStd
MRelRms
mParticleRelStd, mParticleMin, mParticleMax
insertedParticles, insertedParticlesCumulative, lastInsertionStep
kBTWeighted
omegaRms, speedRms
rmsDivParticleAfter
remapMassResidualRelRms, remapMomentumResidualRms
```

A useful regime should keep the cell mass at machine precision, avoid continuous pool consumption, keep particle-mass dispersion moderate, and preserve coherent Q6 structures without catastrophic cooling.
