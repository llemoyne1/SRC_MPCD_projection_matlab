# Weighted-resampling Poiseuille wallVP decisive diagnostics

This patch adds the diagnostic layer needed before judging the weighted-resampled
Poiseuille case physically.

It does not change the wallVP or resampling physics.  It adds:

- live spatial visualisation of the wallVP Poiseuille channel;
- live/final profile visualisation `Ux(y)`;
- explicit slip-aware and no-slip parabolic fits;
- profile CSVs containing the measured profile, fit rows, slip fit, no-slip fit
  and chosen fit;
- additional summary fields: `nuEffSlip`, `R2Slip`, `nuEffNoSlip`,
  `R2NoSlip`, `slipVelocity`, `slipRatio`, `wallSlipRatioObserved`.

The slip-aware fit uses

```text
u(y) = u_slip + A y (H-y),   nu_eff = bodyForceX/(2 A)
```

and is the default for the wallVP validation because any remaining wall slip or
near-wall offset should not by itself corrupt the curvature/viscosity estimate.
The no-slip fit is still reported as a diagnostic.

## Recommended decisive run

```matlab
outW = run_resamp_poiseuille_wallvp_validation( ...
    'steps',10000, ...
    'sampleEvery',50, ...
    'summaryEvery',100, ...
    'visualEvery',200, ...
    'saveFrames',true, ...
    'saveFrameEvery',500, ...
    'saveFinalFigures',true, ...
    'Nx',64, ...
    'Ny',32, ...
    'gamma',20, ...
    'dt',0.005, ...
    'bodyForceX',0.005, ...
    'NMin',14, ...
    'NTarget',20, ...
    'NMax',26, ...
    'ThermostatStrength',0.25, ...
    'wallVirtualParticlesEnable',true, ...
    'wallVirtualParticlesGeometryMode','shifted_solid_fraction', ...
    'wallVirtualParticlesDensityFactor',1.0, ...
    'wallVirtualParticlesThermal',true, ...
    'poiseuilleFitModel','slip', ...
    'excludeWallCells',2, ...
    'fitStartFraction',0.5, ...
    'rngSeed',12345);
```

For a quick smoke, use fewer steps and set `visualEvery` to 25 or 50.

## Files written per case

```text
runs/resamp_poiseuille_wallvp_validation/<case>/timeseries.csv
runs/resamp_poiseuille_wallvp_validation/<case>/profile_late_mean.csv
runs/resamp_poiseuille_wallvp_validation/<case>/frames/*_spatial.png
runs/resamp_poiseuille_wallvp_validation/<case>/frames/*_profile.png
```

## Reading the result

A credible Poiseuille run should show:

- a stable parabolic `Ux(y)` profile in the profile figure;
- `R2Slip` high enough to trust the curvature;
- `slipVelocity` and `wallSlipRatioObserved` small or at least explicitly
  diagnosed;
- `MRelRms` near roundoff on wet cells;
- bounded `mParticleRelStd`;
- stable `kBTWeighted`;
- nonzero wallVP equivalent population near the walls.
